# Vihaans-Stuff

A personal portfolio website built from scratch to showcase my mechanical engineering projects, CAD models, and custom PCB hardware builds (like my custom Macropad!).

# Tech & Tools Used
* HTML5 
* Vanilla JavaScript (Tab-switching interface)
* CAD Modeling (Onshape)
* Custom PCB Design (KiCad

# Features
- Home: About me and featured builds (Macropad & Monaco F1 Trophy).

-Projects: Breakdown of my repositories, code, and design files.
- Contact: Direct links to my GitHub and Email.
